# Become Free — RAG Backend

This is the AI healing companion backend for **The Safe Body** platform, created by Dr. Clarisse Djeumo Djukom, MD.

## What it does
- Powers the **Become Free** AI chat companion at thesafebody.org/become-free/
- Uses TF-IDF retrieval to answer questions about emotional eating, nervous system healing, and trauma-informed wellness
- Responds in Dr. Clarisse's warm, physician voice

## Tech Stack
- FastAPI
- Scikit-learn (TF-IDF)
- Python 3.10+
